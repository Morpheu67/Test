# 🎮 Tetris — Neon Edition

Um jogo de **Tetris desenvolvido com HTML, CSS e JavaScript**, com interface moderna, efeitos visuais e controles responsivos para computador e dispositivos móveis.

O projeto foi criado para explorar o desenvolvimento de jogos diretamente no navegador, sem a necessidade de instalar programas adicionais para jogar.

## ✨ Funcionalidades

- 🧩 Tabuleiro clássico de Tetris com peças coloridas.
- 👻 Projeção da posição em que a peça vai cair (*ghost piece*).
- 🔜 Visualização da próxima peça.
- 🏆 Sistema de pontuação baseado nas linhas eliminadas.
- 📈 Progressão de níveis conforme a pontuação aumenta.
- ⚡ Aumento progressivo da velocidade do jogo.
- 💾 Recorde salvo localmente no navegador.
- ⏸️ Opções para iniciar, pausar e reiniciar a partida.
- 📱 Controles adaptados para dispositivos móveis.
- 🎨 Interface visual moderna e responsiva.

## 🕹️ Como jogar

O objetivo é encaixar as peças para formar linhas horizontais completas. Quando uma linha é preenchida, ela desaparece e você ganha pontos.

Evite deixar as peças acumularem até o topo do tabuleiro!

### Controles

| Tecla | Ação |
|---|---|
| ← | Mover a peça para a esquerda |
| → | Mover a peça para a direita |
| ↓ | Acelerar a descida da peça |
| ↑ | Girar a peça |
| Espaço | Soltar a peça imediatamente |
| P | Pausar ou retomar o jogo |

Em dispositivos móveis, utilize os controles exibidos na interface.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do jogo.
- **CSS3:** interface, layout responsivo e efeitos visuais.
- **JavaScript:** mecânicas, movimentação das peças, colisões, pontuação e progressão dos níveis.
- **LocalStorage:** armazenamento local do recorde.

## 🚀 Como executar

### Jogar diretamente no navegador

Acesse a página publicada do projeto, quando disponível.

### Executar localmente

1. Baixe ou clone este repositório.
2. Localize o arquivo `index.html`.
3. Abra o arquivo em um navegador moderno.
4. Inicie uma partida e divirta-se!

Não é necessário instalar dependências para executar a versão básica do jogo.
